# 발표 스터디 항해 로그

회차별 발표 녹화를 태양계로 보여주는 정적 사이트. 서버가 필요 없다.
회차마다 궤도가 하나씩 바깥으로 늘어나고, 각 궤도에는 발표자의 천체가 공전한다.
행성을 클릭하면 그 회차의 유튜브 녹화가 열린다.

## 배포

정적 파일만으로 돌아간다. 빌드 단계도, 서버도, 데이터베이스도, 유료 서비스도 없다.
GitHub Pages의 무료 범위 안에서 끝난다.

1. 이 폴더의 내용을 저장소 루트에 올린다. **`vendor/`, `fonts/`, `textures/` 폴더를 빼면 안 된다.**
2. Settings → Pages → Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 지정한다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 열린다.

GitHub Actions 워크플로가 필요 없다. `Deploy from a branch`는 파일을 그대로 서빙하기만 한다.
`.nojekyll` 파일이 들어 있어서 Jekyll 변환도 건너뛴다.

### 외부에 의존하지 않는다

three.js와 폰트를 저장소 안에 넣어뒀다. 실행에 필요한 외부 CDN 호출이 0건이다.
사내망에서 외부 CDN이 막혀 있어도 열리고, CDN이 사라지거나 정책을 바꿔도 영향이 없다.

| 파일 | 크기 | 출처 |
|---|---|---|
| `vendor/three.module.min.js` | 687KB | three.js r169, MIT |
| `vendor/OrbitControls.js` | 32KB | three.js 예제, MIT |
| `fonts/Galmuri11.woff2` | 505KB | Galmuri11, SIL OFL 1.1 |

한 번 방문하면 브라우저가 캐시하므로 두 번째 방문부터는 다시 받지 않는다.

폰트가 500KB인 이유는 한글 음절 11,172자를 전부 담고 있어서다. 서브셋이 아니라
CDN을 쓰더라도 같은 용량을 받는다. 그래서 크기 단계는 12px과 24px 두 개만 쓴다.
Galmuri11은 비트맵에서 온 폰트라 설계 크기 12px과 그 배수에서만 픽셀이 정확히 맞고,
13px이나 17px 같은 값을 쓰면 글자가 뭉개진다.

### 유일한 외부 통신

유튜브다. 썸네일 이미지(`i.ytimg.com`)와 재생 iframe(`youtube-nocookie.com`)만 부른다.
둘 다 무료이고 API 키가 필요 없다. 재생 버튼을 누르기 전까지는 iframe이 만들어지지 않으므로
추적 쿠키도 심기지 않는다.

## 로컬에서 확인

`index.html`을 더블클릭하면 브라우저가 `file://`에서 `data.json`을 읽지 못한다.
간단한 서버를 띄워서 열어야 한다.

```bash
python3 -m http.server
# http://localhost:8000
```

## 회차 추가

### 자동: 채널에서 가져오기

유튜브 채널의 영상 목록으로 `sessions`를 채운다. API 키가 필요 없다.

```bash
python3 tools/sync_youtube.py            # 미리보기
python3 tools/sync_youtube.py --write    # data.json에 반영
```

영상 업로드 순서대로 1회차부터 번호가 붙는다(오래된 영상이 안쪽 궤도).
제목 앞에 `[3회차]`, `#3`, `제 3회차 -` 같은 표기가 붙어 있으면 떼어내고 본문만 남긴다.

`presenter`는 유튜브에서 알 수 없으므로 영상 ID로 대조해 **이미 적어둔 이름은 그대로 유지**하고,
새로 들어온 영상에는 `--presenter` 로 지정한 이름(기본값 `미정`)이 들어간다.
반영 후 발표자만 확인해서 고치면 된다. 실행 전 파일은 `data.json.bak`로 백업된다.

| 옵션 | 뜻 |
|---|---|
| `--write` | 없으면 미리보기만 하고 파일을 건드리지 않는다 |
| `--presenter 이름` | 새 영상에 넣을 발표자 |
| `--keep-titles` | 직접 다듬어둔 제목을 유튜브 제목으로 덮어쓰지 않는다 |
| `--channel UC...` | 다른 채널에서 가져온다 |

RSS 피드는 최신 15개까지만 준다. 영상이 그보다 많으면 `pip install yt-dlp` 후 다시 실행하면
전체를 가져온다. 스크립트가 `yt-dlp`가 있는지 먼저 확인한다.

이 스크립트는 배포에 관여하지 않는다. 로컬에서 돌려 `data.json`을 만들고 그 결과만 push하면 된다.
사이트가 실행 중에 유튜브 목록을 조회하는 일은 없다.

### 직접 넣기

`data.json`의 `sessions` 배열에 한 줄 추가한다. 배열 순서가 그대로 궤도 순서다.

```json
{ "no": 15, "date": "2026-09-17", "title": "제목", "presenter": "수양",
  "youtube": "dQw4w9WgXcQ" }
```

- `youtube` — 영상 URL의 `v=` 뒤 11글자. `https://youtu.be/dQw4w9WgXcQ` → `"dQw4w9WgXcQ"`
- 아직 녹화가 없으면 `"youtube": null`. 날짜가 미래면 "예정", 과거면 "신호 없음"으로 표시된다.

회차가 늘어나면 궤도 간격이 좁아지고 행성 크기도 같이 줄어든다. 별도 조정이 필요 없다.

## 스터디원 추가

`data.json`의 `crew`에 한 줄 추가한다. 이름은 `sessions`의 `presenter`와 정확히 같아야 한다.
등록되지 않은 이름은 "미지의 천체"로 나오고 회색 구체가 된다.

```json
"이름": { "kind": "saturn", "texture": "textures/saturn.jpg", "glow": "#D9C08A" }
```

`kind`가 크기와 부속물을, `texture`가 표면을, `glow`가 주변에 번지는 빛 색을 결정한다.
`textures/` 안에 열 종류가 미리 들어 있어서 사람이 늘면 쓰지 않던 천체를 골라 쓰면 된다.

| kind | 천체 | 크기 | 특징 |
|---|---|---|---|
| `moon` | 달 | 0.70 | 분화구 |
| `mercury` | 수성 | 0.66 | 분화구, 가장 작음 |
| `venus` | 금성 | 0.88 | 황산 구름, 대기광 |
| `earth` | 지구 | 0.94 | 대륙과 구름, 대기광 |
| `mars` | 화성 | 0.80 | 극관, 협곡 |
| `jupiter` | 목성 | 1.36 | 가로 띠, 대적점, 가장 큼 |
| `saturn` | 토성 | 1.18 | 기울어진 고리 |
| `uranus` | 천왕성 | 1.00 | 누운 자전축, 대기광 |
| `neptune` | 해왕성 | 0.98 | 대흑점, 대기광 |
| `comet` | 혜성 | 0.56 | 태양 반대쪽으로 뻗는 꼬리 |

크기는 상대값이다. 실제 반지름은 궤도 간격에 비례해 자동으로 정해지므로,
회차가 늘어 궤도가 촘촘해지면 행성도 같이 작아진다.

### 세부 조정

`kind`의 기본값을 바꾸고 싶으면 같은 줄에 덮어쓴다. 넣지 않으면 기본값을 쓴다.

```json
"이름": { "kind": "earth", "texture": "textures/earth.jpg", "glow": "#5FA8D8",
          "size": 1.1, "tilt": 0.4, "atmo": 0.35 }
```

| 값 | 뜻 |
|---|---|
| `size` | 크기 배율 |
| `tilt` | 자전축 기울기 (라디안) |
| `ring` | `"tilt"` 기울어진 고리 / `"upright"` 수직 고리 / `false` 없음 (기본은 토성만 있음) |
| `tail` | `true`면 태양 반대쪽으로 꼬리 |
| `atmo` | 대기광 세기. `0`이면 없음 |

같은 천체를 두 사람이 써도 된다. `glow`만 다르게 주면 궤도에서 구분된다.
텍스처는 발표자 단위로 공유되므로 같은 파일을 여러 명이 써도 GPU 메모리는 한 장만 쓴다.

## 밝기 조절

`data.json`의 `look`.

| 값 | 역할 |
|---|---|
| `sun` | 태양광 세기. 올리면 태양을 향한 면만 밝아지고 명암 대비가 커진다 |
| `ambient` | 환경광. 모든 면을 고르게 밝히지만 올릴수록 구체가 납작해 보인다 |
| `unseen` | 아직 안 본 회차에 곱하는 색. `#FFFFFF`로 두면 시청 여부 구분이 사라진다 |

## 텍스처 교체

`textures/` 안의 파일을 같은 이름으로 덮어쓰면 된다.
**등장방형(equirectangular, 가로:세로 = 2:1)** 이미지여야 구체에 제대로 감긴다.
실제 행성 사진 맵은 NASA의 3D 리소스나 Solar System Scope에서 구할 수 있다(라이선스 확인 필요).

포함된 열 장은 `tools/generate_textures.py`로 생성한 것이다. 색, 띠 개수, 대륙 비율 같은 값을
바꿔 다시 뽑을 수 있다. 지구는 노이즈를 고도로 보고 해수면에서 잘라 대륙을 만들기 때문에,
`sea` 분위값을 바꾸면 육지 비율이 달라진다.

```bash
pip install numpy pillow
python3 tools/generate_textures.py textures
```

## 조작

| | 마우스 | 터치 |
|---|---|---|
| 시점 회전 | 드래그 | 한 손가락 드래그 |
| 확대 축소 | 스크롤 | 두 손가락 오므리기 |
| 회차 열기 | 행성 클릭 | 행성 탭 |

행성에 커서를 올리거나 손가락을 대면 공전이 멈춘다. 움직이는 표적은 누를 수 없기 때문이다.
터치에서는 손가락을 댄 지점 주변까지 판정 범위를 넓혀서 조금 빗나가도 잡힌다.
화면 우상단의 `공전 정지`로 아예 세워둘 수도 있다.

## 시청 기록

브라우저 `localStorage`에 저장된다. 기기마다 따로 남고 스터디원 간에 공유되지 않는다.
공유하려면 서버가 필요해지므로 범위에서 제외했다.

## 파일

```
index.html        3D 화면. 고칠 일 없음
data.json         회차 · 스터디원 · 밝기   <- 여기만 고친다
textures/         행성 표면 10종 (2:1 등장방형)
vendor/           three.js (저장소에 포함)
fonts/            Galmuri11 (저장소에 포함)
tools/            텍스처 생성 · 유튜브 동기화 스크립트. 배포에는 불필요
orrery-css.html   WebGL을 못 쓰는 환경용 2D 대체 화면
.nojekyll         Jekyll 변환 방지
```

`orrery-css.html`은 three.js 없이 CSS만으로 그리는 별도 화면이라 회차 데이터를 파일 안에
따로 들고 있다. `data.json`을 고쳐도 반영되지 않는다. 쓸 일이 없으면 지워도 되고,
그 경우 `index.html`의 오류 안내에 있는 링크도 함께 지우면 된다.
